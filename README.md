# Web-Based Point of Sale (POS) System

## Project Overview
This project is a **Web-Based Point of Sale (POS) System** developed using **HTML, CSS, and JavaScript**. It is designed to be a simple, responsive, and interactive POS system that demonstrates frontend development skills, responsive design, and effective UI interaction.

This assignment was created as part of a student project to learn practical skills in building web applications and handling real-world retail scenarios.

---

## Features

The POS system includes the following key functionalities:

### 1. DailyMart POS (Supermarket Theme)
- Add multiple products to the cart.
- Calculate **subtotal**, **tax**, and **total amount** automatically.
- Manage products with **full CRUD operations** (Create, Read, Update, Delete).
- Search and filter products by name or category.
- Generate receipts for completed orders.
- Responsive design for desktops, tablets, and mobile devices.

*Optional: You can also implement other themes such as:*
- **GrillMaster POS (Burger Shop)** – Manage burgers, fries, and drinks.
- **FashionRack POS (Clothing Shop)** – Manage clothes by category and apply discounts.

## Technologies Used
- **HTML5** – Structure and layout of the web pages.
- **CSS3** – Styling, responsive design, and layout.
- **JavaScript** – Dynamic functionality, cart management, and local storage.
- **Local Storage** – To store products, cart items, and orders persistently in the browser.
